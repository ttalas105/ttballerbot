# Rajan spectator

Mode: Operate. Extend the existing player identity in DESIGN.md.

Users are friends watching a game or video in a Discord call, on the Windows computer hosting ttballerbot. A private six-digit Discord code pairs a local browser. Browser-owned selection determines the shared window. Preview and stop controls dominate; style and cadence stay adjacent. Use the existing green/mint palette and Barlow Condensed titles, with familiar accessible controls and plain text status.

Required states: disconnected, pairing error, paired, picker cancelled, sharing, processing, quiet scene, reaction ready, stale result, stopped, expired. Stop must halt capture and pending audio. Mobile layout is readable but screen selection requires a supporting desktop browser. No decorative thinking animation or sound, no invented latency claim.
